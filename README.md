### Régimen de aprobación

Se deben aprobar dos exámenes parciales. Habrá dos fechas de recuperación
al finalizar el cuatrimestre, una para cada examen. Para poder ser incluido
en las actas de trabajos prácticos, es necesario haberse inscripto, mediante
el [sistema
de inscripciones de la facultad](http://www.inscripciones.fcen.uba.ar/)

### Correlatividades

Para cursar es necesario tener aprobados los trabajos prácticos de
Probabilidades y Estadística y el final de Cálculo Avanzado.
